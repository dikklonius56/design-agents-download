Сначала установите
Редактор VS Code ↗ Ассистент Claude Code ↗
Как запустить:
  1. Установите VS Code и Claude Code.
  2. Скачайте архив выше и распакуйте в удобную папку.
  3. Откройте папку в VS Code (Open Folder) и подключите плагин Claude Code.
  4. Напишите Claude: «настрой меня».

Обновления: скажите Claude «обнови агентов» — система подтянет свежую версию.
